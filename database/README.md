# Database setup

The scripts target MySQL 8.0. Run them from the repository root using a MySQL administrator account. Before running `04_roles_and_grants.sql`, replace its three `CHANGE_ME_*_PASSWORD` values with the credentials configured for the backend. Do not commit real passwords.

In PowerShell, run the following commands individually and enter the MySQL administrator password when prompted:

```powershell
mysql -u root -p --execute="source database/01_schema.sql"
mysql -u root -p --execute="source database/02_triggers.sql"
mysql -u root -p --execute="source database/03_views_procedures.sql"
mysql -u root -p --execute="source database/04_roles_and_grants.sql"
mysql -u root -p --execute="source database/05_seed.sql"
```

To run the trigger and rollback checks and the query examples:

```powershell
mysql -u root -p --execute="source database/tests.sql"
mysql -u root -p --execute="source database/06_demo_queries.sql"
```

Verify seeded table counts:

```sql
USE billing_db;
SELECT 'roles' AS table_name, COUNT(*) AS row_count FROM roles
UNION ALL SELECT 'users', COUNT(*) FROM users
UNION ALL SELECT 'customers', COUNT(*) FROM customers
UNION ALL SELECT 'categories', COUNT(*) FROM categories
UNION ALL SELECT 'tax_rates', COUNT(*) FROM tax_rates
UNION ALL SELECT 'products', COUNT(*) FROM products
UNION ALL SELECT 'stock', COUNT(*) FROM stock
```
